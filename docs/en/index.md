# Welcome to BeetVault Documentation

BeetVault is a secure, multi-chain cryptocurrency wallet that supports BitShares, Hive, Vaulta, and many other blockchains. This documentation will help you get started and make the most of your wallet.

## What is BeetVault?

BeetVault is a desktop application that allows you to:

- **Manage multiple blockchain accounts** in a single interface
- **Sign transactions** securely with your private keys stored locally
- **Interact with dApps** through deep links, QR codes, and injected calls
- **Back up and restore** your wallet with encrypted backup files

## Wallet Operations

- **TOTP Deeplink** — Generate time-limited authentication codes for dApp interactions
- **Raw Deeplink** — Process unencrypted transaction payloads from dApps
- **QR Code** — Scan, drag, or upload QR codes containing transaction data
- **JSON File** — Upload JSON files with transaction payloads
- **Sign Message** — Sign arbitrary messages to prove account ownership
- **Verify Message** — Verify a signed message against a public key
