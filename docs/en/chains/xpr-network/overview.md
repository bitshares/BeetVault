# XPR Network

XPR Network, formerly known as Proton, is an Antelope-based blockchain launched in 2020 with a focus on consumer payments and identity. It differentiates itself through an optional on-chain verified identity layer intended to make crypto payments viable for regulated commerce.

The network provides free transactions for most user activity, a built-in decentralised exchange, and account names that double as payment identifiers. Block production uses delegated proof-of-stake with elected block producers.

See [Operations](./operations.md) for the full list of actions BeetVault can broadcast on XPR Network.

## Technical Specifications

| Property | Value |
|----------|-------|
| Framework | Antelope (formerly EOSIO) |
| Consensus | Delegated Proof-of-Stake (DPoS) |
| Block time | ~0.5 seconds |
| Core token | XPR |
| Account model | Human-readable account names with hierarchical permissions |
| Distinguishing feature | Optional on-chain verified identity |
| Transport | HTTP JSON-RPC |
| Launched | 2020 (rebranded from Proton) |
